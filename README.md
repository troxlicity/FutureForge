# Future Forge — animated signup site

## Run locally

```bash
npm install
npm run dev
```

## Supabase setup

1) Copy `.env.example` to `.env.local` and fill in:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

2) In Supabase, create a table named `event_signups` with this SQL:

```sql
create table if not exists public.event_signups (
  id bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  event text not null default 'Future Forge',
  source text not null default 'landing',
  name text not null,
  email text not null,
  timezone text not null
);

create unique index if not exists event_signups_email_event_unique
  on public.event_signups (lower(email), event);

alter table public.event_signups enable row level security;

-- Allow anonymous inserts from the landing page (no reads).
drop policy if exists "anon can insert signups" on public.event_signups;
create policy "anon can insert signups"
  on public.event_signups
  for insert
  to anon
  with check (true);
```

3) Restart the dev server after adding `.env.local`.
